# Spam Email Classification

## About This Project
This is my first beginner-level Machine Learning project using Python and Scikit-learn.

## Objective
To understand how a Machine Learning model can classify data into two categories:
- Spam
- Not Spam

## Technologies Used
- Python
- Scikit-learn

## Concepts Learned
1. Importing a Machine Learning model
2. Creating Features and Labels
3. Creating a Decision Tree Classifier
4. Training a model using `fit()`
5. Making predictions using `predict()`

## Algorithm
Decision Tree Classifier

## Project Status
Beginner Learning Project

## Note
This project uses a small, manually created numerical dataset for learning model training and prediction. It is a simplified demonstration, not a real email-text spam detection system.
